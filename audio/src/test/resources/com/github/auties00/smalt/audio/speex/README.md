# Speex test vectors

Self-generated by `tools/testdata/speex-oracle/make-vectors.py`: inputs synthesized by ffmpeg's `aevalsrc`, encoded
by ffmpeg's libspeex encoder (libspeex 1.2) in Ogg in the mode, quality, bit rate control, discontinuous transmission
and frames per packet each name gives, and decoded by `smalt-speexdec` (`tools/testdata/speex-oracle`, the
fixed-point libspeex 1.2.1 decoder built from its release source, BSD 3-Clause, enhancer on) to record the MD5 of the
16-bit little-endian decode in `expected.tsv`, also with every third packet lost. `../speex.sha256` pins every file.
