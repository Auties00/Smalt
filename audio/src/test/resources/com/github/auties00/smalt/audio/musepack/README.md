# Musepack test vectors

Self-generated by `tools/testdata/musepack/make-vectors.py`: every input is synthesized by the script (tones,
chirps, seeded noise and silence as WAVE), encoded with mpcenc 1.30.1 of musepack_src_r475 (stream version 8) at
the profile in each name, and decoded with `tools/testdata/musepack-oracle/smalt-mpcdec`, a driver of libmpcdec
r475 (BSD 3-Clause, floating-point build), to record the MD5 of the raw float decode in `expected.tsv`.
`../musepack.sha256` pins every file.
