# WavPack test vectors

Self-generated by `tools/testdata/wavpack/make-vectors.py`: every input is synthesized by the script (sines,
chirps and seeded noise as WAVE, a second-order sigma-delta tone as DSF), encoded with the WavPack 5.8.1 command
line encoder built from its release source (BSD 3-Clause), and decoded with the matching `wvunpack -r` (with
`--raw-pcm` for DSD, and `-i` for the lossy decode of the hybrid lossless vectors) to record the MD5 of the raw
decode in `expected.tsv`. The `.wvc` files are the correction files of the hybrid lossless vectors.
`../wavpack.sha256` pins every file.
