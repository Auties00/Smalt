# Monkey's Audio test vectors

Self-generated by `tools/testdata/ape/make-vectors.py`: every input is synthesized by the script (sines, chirps,
seeded noise, silence and identical channels as WAVE), encoded with the Monkey's Audio 13.45 command line tool built
from its SDK source (BSD 3-Clause) at the compression level in each name, and decoded with the same tool to record
the MD5 of the reference decode in `expected.tsv`. `../ape.sha256` pins every file.
