# Opus neural extension unit vectors

`dnn-units.bin` is self-generated by `tools/testdata/opus-oracle/dnnunit.c`, linked by `build.py` with libopus 1.5.2
built with ENABLE_DEEP_PLC, ENABLE_DRED and ENABLE_OSCE and the generic C code of its networks. It holds the outputs of
the activation approximations, the LPCNet feature analysis, the Burg cepstrum, the FARGAN vocoder, the deep PLC, the
RDOVAE decoder and the LACE and NoLACE enhancers on deterministic inputs that `OpusDnnUnitTest` regenerates the same
way. Regenerate with `dnnunit dnn-units.bin`; `../dnn.sha256` pins it.
